# RentFlock

**Find your flock. Find your place.**

A real-time network connecting renters who need a helping hand with verified local people who can provide one.

demo - simple end-to-end flow.

## Stack

- **Backend:** Python + Flask
- **Database:** SQLite + SQLAlchemy
- **Frontend:** HTML + CSS + vanilla JS + Jinja2
- **AI:** OpenAI (optional) or built-in rule-based analysis

## Quick start

```bash
cd rent_flock

# create and activate venv
python -m venv venv
source venv/bin/activate

# install requirements
pip install -r requirements.txt

# run the demo itself
python app.py
